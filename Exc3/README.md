## Роадмап

| **№** | **Этап**                     | **Результат**                                                                    | **Ответственные команды**     | **Ресурсы**                |
|-------|------------------------------|----------------------------------------------------------------------------------|-------------------------------|----------------------------|
| 1     | Проектирование               | Уточнение доменов, описание потоков данных и проектирование Data LakeHouse       | Архитекторы, аналитики данных | 2 месяца, проектный бюджет |
| 2     | Развертывание Data LakeHouse | Развернут Data LakeHouse, подключены первые (финансовые) домены                  | DevOps                        | 3 месяца, инфраструктура   |
| 3     | Миграция данных              | Настроен постепенный перенос исторических данных из Legacy DWH в Data LakeHouse  | Data инженеры                 | 6 месяцев, ETL-инструменты |

## Обоснование изменений

1. **Разделение доменов и проектирование**
    - Обеспечивает независимость развития бизнес-направлений
    - Позволяет минимизировать изменения в Legacy DWH

2. **Развертывание Data LakeHouse**
    - Создает централизованный слой аналитики
    - Ускоряет доступ к данным и снижает нагрузку на Legacy DWH

3. **Миграция данных**
    - Постепенно снижает зависимость от устаревшего SQL Server
    - Упрощает долгосрочную поддержку хранилища

4. **Создание API Gateway**
    - Обеспечивает стандартизацию обмена данными
    - Упрощает подключение новых бизнесов
