## Проблемные места

| Проблема                     | Описание                                                                                                                                   |
|------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| Медленный DWH                | DWH на базе Microsoft SQL-сервера 2008 года морально устарела, поддержка закончилась в 2019 году и плохо масштабируется                    |
| Старая шина данных           | Интеграционная шина данных на основе Apache Camel недостаточно масштабируема и требует постоянных обновлений со стороны команды разработки |
| Разрозненные данные          | Нет централизованной модели данных, сложность интеграции новых бизнесов                                                                    |
| Много бизнес-логики в DWH    | Большое количество бизнес-логики реализовано в DWH, что вызовет сложности при добавлении новых бизнесов                                    |
| Ограничения PowerBuilder     | Ограниченные возможности PowerBuilder для масштабирования и гибкости                                                                       |
| Сложности с отчётами         | Сложные отчёты можно ждать часами из-за большого количества трансформаций                                                                  |
| Уязвимости в безопасности    | Отсутствие централизованного управления доступами                                                                                          |

## Приоритизация по MoSCoW

| Категория | 	Проблема                  | Обоснование                                                                                   |
|-----------|----------------------------|-----------------------------------------------------------------------------------------------|
| Must      | Медленный DWH              | Блокирует реализацию витрины данных и масштабирование аналитики                               |
| Must      | Разрозненные данные        | Усложняет интеграцию новых бизнесов и снижает прозрачность                                    |
| Must      | Сложности с отчётами       | Задержки с отчетностью могут повлечь финансовую, административную и уголовную ответственность |
| Should    | Старая шина данных         | Повышение масштабируемости и надёжности интеграции                                            |
| Should    | Ограничения PowerBuilder   | Устаревшая технология требует обновления для оптимальной работы системы                       |
| Could     | Уязвимости в безопасности  | Важно для долгосрочной надёжности                                                             |
| Won’t     | Много бизнес-логики в DWH  | Можно решить позже при внедрении новых инструментов                                           |
